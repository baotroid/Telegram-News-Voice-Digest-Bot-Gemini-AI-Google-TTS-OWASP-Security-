## 1. Как устроен многопользовательский режим

Бот в данном проекте уже **полностью оптимизирован для работы с неограниченным количеством пользователей**:
- 👤 **Изоляция данных**: каждый пользователь настраивает **свой собственный список каналов** (`/channels`).
- 🎙️ **Личный голос**: каждый пользователь сам выбирает один из 4 голосов (`/voice`).
- ⏰ **Персональное расписание**: каждый пользователь настраивает свое удобное время утреннего дайджеста (`/time`).
- 🔒 **Шифрование данных (OWASP)**: базы настроек пользователей шифруются ключом Fernet (`services/storage.py`), защищая персональные данные.
- 🛡️ **Защита от спама (Rate Limiter)**: модуль `security.py` предотвращает перегрузку Gemini API и флуд от пользователей.

## 2. Бесплатные ключи и API (0 рублей навсегда)

Вам понадобятся 3 бесплатных ключа:

### А. Токен Telegram-бота (Bot Token)
1. Откройте в Telegram официального бота: [@BotFather](https://t.me/BotFather).
2. Отправьте команду: `/newbot`.
3. Введите название бота (например, `My News AI Digest`).
4. Введите юзернейм бота, оканчивающийся на `bot` (например, `MySuperNews_ai_bot`).
5. Скопируйте полученный токен (вида `7123456789:AAFnk9...`).

### Б. Telegram API ID и API Hash (для чтения каналов)
*Необходимы Telethon для чтения публичных постов из каналов без спам-блокировок.*
1. Перейдите на официальный портал: [my.telegram.org](https://my.telegram.org).
2. Авторизуйтесь под своим номером Telegram.
3. Перейдите в раздел **«API development tools»**.
4. Заполните название приложения (любое, например `NewsReader`) и нажмите **«Create application»**.
5. Скопируйте **`api_id`** (число) и **`api_hash`** (строка).

### В. Ключ Google Gemini API
1. Перейдите в [Google AI Studio](https://aistudio.google.com/).
2. Нажмите кнопку **«Get API Key»** → **«Create API Key»**.
3. Скопируйте ключ (бесплатный тариф предоставляет щедрые лимиты, более чем достаточные для сотен дайджестов в день).

### Г. Озвучка Edge-TTS
- **Никаких ключей не требуется!** Библиотека `edge-tts` использует высококачественные нейросети Microsoft бесплатно без авторизации и скрытых лимитов.

## 3. Быстрый локальный запуск (за 3 минуты)

Если вы хотите запустить бота на своем компьютере (Windows, Mac или Linux):

### Шаг 1: Скачайте проект
В веб-студии нажмите **«Скачать проект (ZIP)»** в разделе «Центр Python-кода» и распакуйте архив в отдельную папку.

### Шаг 2: Установите Python 3.10+
Убедитесь, что установлен Python ([python.org](https://www.python.org/downloads/)).

### Шаг 3: Установите зависимости
В терминале / командной строке перейдите в папку с проектом и выполните:
```bash
pip install -r requirements.txt
```

### Шаг 4: Заполните файл `.env`
Переименуйте `.env.example` в `.env` (или создайте `.env`) и укажите ваши ключи:
```ini
TELEGRAM_BOT_TOKEN=ваш_токен_из_BotFather
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
GEMINI_API_KEY=ваш_gemini_api_key

# Сгенерировать ключ шифрования можно командой: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
ENCRYPTION_KEY=любой_фернет_ключ_или_оставьте_пустым_для_автогенерации
```

### Шаг 5: Первый запуск и авторизация Telethon
Запустите бота:
```bash
python bot.py
```
При первом запуске Telethon в терминале один раз запросит номер телефона и код из Telegram для создания сессии чтения публичных постов (создастся файл `telegram_reader.session`).

**Готово!** Бот онлайн и отвечает всем пользователям в Telegram.

## 4. Бесплатный хостинг 24/7 (Бот работает непрерывно)

Чтобы бот работал круглосуточно, когда ваш компьютер выключен, разместите его на одном из бесплатных облачных сервисов:

---

### Вариант А: Render.com (Бесплатно и удобно)
[Render.com](https://render.com) предоставляет бесплатный тариф для хостинга приложений.

1. **Создайте репозиторий на GitHub**:
   - Создайте приватный или публичный репозиторий на [github.com](https://github.com).
   - Загрузите все файлы проекта из архива (кроме `.env` и `.session`).
2. **Зарегистрируйтесь на Render**:
   - Войдите через GitHub на [render.com](https://render.com).
   - Нажмите **«New +»** → **«Background Worker»** (или **«Web Service»**).
   - Подключите ваш репозиторий с ботом.
3. **Настройки**:
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
4. **Переменные окружения (Environment Variables)**:
   - В разделе **«Environment»** добавьте:
     - `TELEGRAM_BOT_TOKEN`
     - `TELEGRAM_API_ID`
     - `TELEGRAM_API_HASH`
     - `GEMINI_API_KEY`
     - `ENCRYPTION_KEY`
     - `TELETHON_SESSION_STRING` (строка сессии Telethon, полученная локально, чтобы не требовался ввод кода в облаке).
5. Нажмите **«Deploy»**. Бот запустится и будет работать в облаке 24/7.

---

### Вариант Б: Koyeb / Railway
- **Koyeb** ([koyeb.com](https://www.koyeb.com/)): предоставляет бесплатный Nano-инстанс. Поддерживает запуск через Dockerfile (`Dockerfile` уже есть в проекте).
- **Railway** ([railway.app](https://railway.app/)): дает бесплатные стартовые часы/кредиты каждый месяц. Запуск в 1 клик через `Dockerfile`.

---

### Вариант В: Oracle Cloud Always Free Tier (Самый мощный вариант)
Oracle Cloud бесплатно предоставляет виртуальный сервер (4 ядра ARM, 24 ГБ RAM, 200 ГБ диск) **навсегда бесплатно**:
1. Зарегистрируйтесь на [oracle.com/cloud/free](https://www.oracle.com/cloud/free/).
2. Создайте виртуальную машину Ubuntu (Compute Instance).
3. Подключитесь по SSH: `ssh ubuntu@IP_СЕРВЕРА`.
4. Установите Docker:
   ```bash
   sudo apt update && sudo apt install -y docker.io docker-compose git
   ```
5. Склонируйте проект и запустите в фоне:
   ```bash
   docker-compose up -d --build
   ```
Бот будет работать вечно без перезагрузок и лимитов.

---

### Вариант Г: Домашний ПК / Ноутбук / Raspberry Pi
Если у вас есть старый ноутбук, мини-ПК или Raspberry Pi:
1. Запустите бота через `systemd` службу (на Linux) или через Docker:
   ```bash
   docker-compose up -d
   ```
2. Бот потребляет менее 150 МБ оперативной памяти и практически не нагружает процессор.

## 5. Как дать доступ другим пользователям

1. Откройте Telegram и найдите вашего бота по его юзернейму (например, `@MySuperNews_ai_bot`).
2. Скопируйте ссылку на бота: `https://t.me/MySuperNews_ai_bot`.
3. Отправьте эту ссылку друзьям, коллегам или опубликуйте в канале.
4. **Что происходит, когда другой человек открывает бота**:
   - Он нажимает кнопку **Start** (`/start`).
   - Бот создает для него отдельный защищенный профиль.
   - Пользователь вводит список интересующих его каналов (например, `durov, bbcrussian, habr_pop`).
   - Выбирает понравившийся голос (`/voice`) и удобное время (`/time`).
   - Нажимает `/news` и мгновенно получает свой персональный текстовый и голосовой выпуск новостей!

## 6. Команды бота для пользователей

| Команда | Что делает |
| :--- | :--- |
| **`/start`** | Приветствие, регистрация и краткий гид по функциям |

| **`/help`** | Справка и часто задаваемые вопросы |

## 7. Решение частых проблем (Troubleshooting)

### В: Что делать, если при запуске в облаке Telethon просит ввести код из SMS?
**О:** Для облачных серверов без интерактивного терминала используется `StringSession`:
1. Запустите один раз локально скрипт генерации сессии:
   ```python
   from telethon.sync import TelegramClient
   from telethon.sessions import StringSession

   with TelegramClient(StringSession(), API_ID, API_HASH) as client:
       print("Ваша строка сессии:")
       print(client.session.save())
   ```
2. Вставьте полученную строку в переменную окружения `TELETHON_SESSION_STRING` на хостинге.

### В: Сколько пользователей выдержит бесплатный бот?
**О:** Благодаря асинхронной архитектуре (`Aiogram 3` + `Telethon` + неблокирующий `edge-tts`) и встроенному кэшированию, бот легко обслуживает от **500 до 5 000+ активных пользователей** на бесплатном инстансе.

### В: Работает ли озвучка на русском и английском языках?
**О:** Да! Встроены 4 официальных голоса:
- `1. Русский — Дмитрий (Мужской)`
- `2. Русский — Светлана (Женский)`
- `3. English — Guy (Male)`
- `4. English — Jenny (Female)`
